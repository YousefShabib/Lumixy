ثانياً: الملفات المشتركة التي تخدم صفحات الأدمن

الملف وظيفته ملاحظات للمناقشة
contexts/admin-session-context.tsx إدارة جلسة الأدمن: login، logout، تحديث البروفايل، إنشاء أدمن، وقراءة بيانات الأدمن الحالي. مثال قوي على Context API و useCallback و useMemo.
contexts/AuthContext.tsx الجلسة العامة للتطبيق: تخزين token/user/role وتوفيرها لكل التطبيق. يعمل فوق SecureStore ويحمي التنقل حسب الدور.
services/storage.ts حفظ وقراءة وحذف التوكن وبيانات المستخدم باستخدام expo-secure-store. مهم جداً لسؤال Authentication و secure token storage.
services/admin-api.ts كل طلبات API الخاصة بالأدمن: المزودين، التصنيفات، حسابات الأدمن، وتعديل البروفايل. يفصل منطق الاتصال بالباك عن الواجهة.
services/admin-auth-api.ts طلبات login/logout/me الخاصة بالأدمن. يعتمد على apiRequest ويستخدم token عند الطلبات المحمية.
services/api.ts طبقة الاتصال العامة: Axios، بناء رابط API، إضافة Authorization، وتحويل الأخطاء إلى رسائل مقروءة. مكان ممتاز لشرح error handling و Axios.
hooks/admin/use-admin-providers.ts جلب المزودين وتحويل شكل الداتا للواجهة، وإدارة mutations للقبول/الرفض/الإيقاف/الحذف. مثال واضح على TanStack Query و query invalidation.
hooks/admin/use-admin-categories.ts جلب التصنيفات وإضافة/تعديل/حذف تصنيف مع تحديث الكاش. Custom hook ينظف الصفحات من منطق API.
hooks/admin/use-admin-accounts.ts جلب حسابات الأدمن، إنشاء أدمن، حذف أدمن، وتحديث بروفايل الأدمن. يستخدم React Query و Haptics feedback بعد النجاح.
components/admin/admin-categories-screen.tsx كومبوننت كامل لإدارة التصنيفات، يستخدم في صفحتين بوضعين مختلفين. مثال على إعادة استخدام الكومبوننت و useRef و react-hook-form.
components/admin/admin-detail-shell.tsx قالب موحد لصفحات التفاصيل في الأدمن مع header، زر رجوع، notice، و scroll layout. يساعد على توحيد UI/UX بين صفحات الأدمن.

رابعاً: وظيفة المكتبات والمفاهيم بشكل عام

المكتبة / المفهوم وظيفتها بشكل عام مثال استخدام
react-hook-form مكتبة لإدارة النماذج داخل React و React Native. تساعد على قراءة قيم الحقول، التحقق من المدخلات، عرض رسائل الخطأ، وتقليل إعادة التصيير غير الضرورية مقارنة بإدارة كل input يدوياً. Login form، Add form، Edit profile form.
TanStack React Query مكتبة لإدارة بيانات السيرفر داخل الواجهة. تهتم بجلب البيانات، الكاش، حالات التحميل والخطأ، إعادة الجلب، وتحديث البيانات بعد عمليات مثل الإضافة والحذف والتعديل. useQuery للقراءة و useMutation للتعديل.
Device Features استخدام ميزات الجهاز الحقيقية مثل الكاميرا، الميكروفون، الموقع، البصمة أو Face ID. تضيف للتطبيق تفاعل مباشر مع الهاتف بدل أن يكون مجرد صفحات عادية. اختيار صورة، التقاط صورة، قراءة location، Face ID login.
UI/UX تصميم الواجهة وتجربة الاستخدام. UI يهتم بشكل العناصر والألوان والتنسيق، بينما UX يهتم بسهولة الاستخدام، وضوح الخطوات، سرعة الوصول للمعلومة، وحالات التحميل والخطأ. Cards، tabs، buttons واضحة، loading/error states.
SQLite قاعدة بيانات محلية خفيفة تعمل داخل الجهاز. تستخدم لتخزين بيانات offline حتى يستطيع المستخدم فتح صفحة أو قراءة بيانات بدون اتصال إنترنت. صفحة مفضلة أو ملاحظات تعمل بدون شبكة.
Test Case اختبار برمجي يتأكد أن جزء من التطبيق يعمل كما هو متوقع. يمكن أن يختبر كومبوننت، دالة، أو سلوك معين مثل ظهور نص أو تنفيذ زر. اختبار أن Button يعرض loading عند الضغط.
Axios مكتبة لإرسال طلبات HTTP بين الفرونت والباك. تستخدم لتنفيذ GET و POST و PUT و DELETE، وتسهّل إضافة headers مثل Authorization ومعالجة الأخطاء. Login request، fetch users، delete item.
File Structure طريقة ترتيب ملفات المشروع في مجلدات واضحة حسب المسؤولية. الهدف أن يكون المشروع سهل الفهم والتوسعة والصيانة. screens، components، hooks، services.
Clean Code & Best Practices كتابة كود واضح، مقروء، قابل للصيانة، ويفصل المسؤوليات. يشمل تسمية جيدة، تقليل التكرار، تقسيم الكود، ومعالجة الحالات المختلفة بشكل منظم. فصل API في services بدل كتابته داخل الشاشة.
Custom Hooks دوال React تبدأ بـ use وتجمع منطقاً قابلاً لإعادة الاستخدام. تساعد على نقل logic خارج الكومبوننت حتى تبقى الواجهة أنظف. useAuth، useUsersQuery، usePersistedState.
Context API ميزة من React لمشاركة state أو functions بين أجزاء التطبيق بدون تمرير props في كل مستوى. مناسبة للجلسة، الثيم، اللغة، أو بيانات المستخدم العامة. Auth context، Theme context، Language context.
Async Storage تخزين محلي غير حساس على الجهاز بنظام key-value. يستخدم لحفظ تفضيلات أو بيانات بسيطة لا تحتاج حماية عالية. حفظ theme، آخر بحث، إعدادات المستخدم.
Error Handling التعامل مع الأخطاء بطريقة منظمة بدل أن ينهار التطبيق. يشمل التقاط أخطاء الشبكة، أخطاء التحقق، أخطاء الصلاحيات، وعرض رسالة واضحة للمستخدم. رسالة عند فشل login أو انقطاع الإنترنت.
useCallback Hook يحفظ نفس نسخة الدالة بين عمليات التصيير ما دامت dependencies لم تتغير. يستخدم لتقليل إعادة التصيير وتمرير دوال ثابتة للكومبوننتات. تثبيت function مثل logout أو submitForm.
useMemo Hook يحفظ نتيجة عملية حسابية ويعيد حسابها فقط عند تغير dependencies. مفيد مع الفلترة، الترتيب، أو العمليات المكلفة. فلترة list حسب البحث والحالة.
useRef Hook يحتفظ بقيمة قابلة للتغيير بدون أن يسبب إعادة تصيير. يستخدم للوصول لعناصر UI أو حفظ قيمة بين renders. التحكم بـ ScrollView أو TextInput focus.
